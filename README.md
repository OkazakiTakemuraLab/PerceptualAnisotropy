# PerceptualAnisotropy

Repository for data and code for replicating results and figures of the following paper:

Luo, J., Ashida, H., Yokoi, I. & Takemura, H. (in prep) The anisotropic sensitivities of perceptual speed between expanding and contracting optic flows.

The code was written in MATLAB2024a and tested on Ubuntu 20.04 LTS.

Dependency:
Running codes in this repository requires the Palamedes toolbox, which can be obtained from the following URL:
https://www.palamedestoolbox.org/download.html

The original paper of the Paramedes toolbox:
Prins, N. & Kingdom, F.A.A. (2018). Applying the Model-Comparison Approach to Test Specific Research Hypotheses in Psychophysical Research Using the Palamedes Toolbox. Frontiers in Psychology, 9:1250.

We note that this repository includes code derived from four external public MATLAB repositories:

[1] Bechtold, B. (2016) Violin Plots for Matlab, Github Project (https://github.com/bastibe/Violinplot-Matlab, DOI: 10.5281/zenodo.4559847)

[2] Danz, A. (2025) boxplotGroup (https://jp.mathworks.com/matlabcentral/fileexchange/74437-boxplotgroup), MATLAB Central File Exchange.
