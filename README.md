# PerceptualAnisotropy

Repository for data and code for replicating results and figures of the following paper:

Luo, J., Ashida, H., Yokoi, I. & Takemura, H. (2026) Anisotropic speed discrimination sensitivity for expanding and contracting optic flow. Journal of Vision, 26(10):18, 1–17.

The code was written in MATLAB2024a and tested on Ubuntu 20.04 LTS.

We note that this repository also includes code derived from following external public MATLAB repositories:

[1] Bechtold, B. (2016) Violin Plots for Matlab, Github Project (https://github.com/bastibe/Violinplot-Matlab, DOI: 10.5281/zenodo.4559847)

[2] Danz, A. (2025) boxplotGroup (https://jp.mathworks.com/matlabcentral/fileexchange/74437-boxplotgroup), MATLAB Central File Exchange.

[3] Prins, N. & Kingdom, F.A.A. (2018). Applying the Model-Comparison Approach to Test Specific Research Hypotheses in Psychophysical Research Using the Palamedes Toolbox. Frontiers in Psychology, 9:1250. (https://www.palamedestoolbox.org/download.html)
